v8基础

前言

V8 是 Google 开发的 JavaScript 引擎，主要作用是把 JavaScript 代码解析、编译并执行起来

常用于：

  1. Chrome/Chromium：执行网页中的 JavaScript
  2. Node.js：让 JavaScript 能在服务器和命令行运行
  3. Electron、Deno 等程序：作为内置脚本引擎。

环境搭建

build.sh–>自动切换 V8 源码到指定版本，拉取依赖，生成 GN 构建配置，然后编译出一个用于调试/漏洞研究的 d8（二进制 JavaScript shell）

v8漏洞利用原理

V8 Pwn 的核心就是利用 V8 对象结构（Map、elements、length）的信任，通过类型混淆把 JavaScript 的对象引用和浮点数互相转换，从而泄露地址、伪造对象，最终获得任意地址读写，再利用 WASM 或其他目标实现代码执行。
