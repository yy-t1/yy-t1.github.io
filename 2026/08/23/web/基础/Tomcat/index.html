Tomcat

基础

Tomcat 是一个 Java Web 应用服务器，主要负责运行 Java Servlet / JSP Web 应用

（Tomcat 是一个 Servlet 容器）

核心层级

组件 作用
Server 整个 Tomcat 容器
Service 把 Connector 和 Engine 组合起来
Connector 监听端口、处理 HTTP
Engine 根据 Host 处理请求
Host 虚拟主机，例如 localhost
Context 一个 Web 应用
Wrapper 一个 Servlet 的包装对象
Servlet 真正处理请求的 Java 类

Servlet

Servlet = 运行在 Web 服务器中的 Java 程序组件，专门负责接收 HTTP 请求、处理业务，然后返回 HTTP 响应。
