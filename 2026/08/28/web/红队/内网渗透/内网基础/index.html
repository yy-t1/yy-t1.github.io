内网基础

一.简介

内网（Internal Network）就是组织内部用于连接服务器、员工电脑、数据库、办公设备等资源的网络。

区域 定位 典型资产
边界互联区 内外网出入口 防火墙、VPN 网关、路由器、IPS
DMZ 区 对外提供服务 Web 网站、邮件前端、API 网关
办公区 员工日常办公 办公 PC、打印机、WiFi
运维管理区 全域管控 堡垒机、监控、漏洞扫描器、跳板机
内网服务区 核心业务 OA/ERP/CRM、数据库、文件服务器、Gitlab
研发测试区 开发测试 测试服务器、CI/CD、代码仓库
核心保密区 机密数据 财务系统、源代码、涉密数据（常加网闸隔离）

（外网可以访问DMZ区，DMZ区无法访问外网以及内网）

二.常见内网设备

防火墙

根据预先设置的规则，决定哪些网络流量可以通过，哪些必须拦截。

绕过方法

VPN

VPN（虚拟专用网络）在公网上建立加密隧道，实现远程安全接入或站点互联。是企业内网暴露在公网的最常见入口。

攻击方法

蜜罐

蜜罐是故意部署的诱饵系统，通过模拟真实服务/资产吸引攻击者交互，从而检测、延迟和分析攻击行为。

识别蜜罐

WAF

Web 应用防火墙（Web Application Firewall）

通过分析 HTTP/HTTPS 流量识别和阻止 Web 攻击（SQL 注入、XSS、命令注入、文件包含、CSRF 等）。
