subfinder

被动子域名枚举器

核心原理：通过收集互联网公开信息源（Passive Sources）中的域名记录，经过去重、验证、整理，得到目标域名的子域名列表。

（不是扫描的）

子域名

目标：example.com

常见：

子域名 用途
www 官网
api 接口服务器
admin 后台
mail 邮件
dev 开发环境
test 测试环境
vpn VPN入口

使用说明

参数 全称 作用 示例
-d domain 指定目标域名 subfinder -d example.com
-dL domain list 从文件读取多个域名 subfinder -dL domains.txt
-o output 输出结果到文件 subfinder -d example.com -o result.txt
-oJ output json JSON格式输出 subfinder -d example.com -oJ result.json
-v verbose 显示详细过程 subfinder -d example.com -v
-silent 静默模式 只输出结果，不显示日志 subfinder -d example.com -silent
-all all sources 使用全部数据源 subfinder -d example.com -all
-recursive recursive 递归寻找子域 subfinder -d example.com -recursive
-nW no wildcard 不显示泛解析结果 subfinder -d example.com -nW
-t threads 设置并发数量 subfinder -d example.com -t 50

常用：

场景 命令 说明
收集单个域名 subfinder -d example.com 最基础用法
收集学校域名 subfinder -d fjnu.edu.cn 根域名收集
保存结果 subfinder -d example.com -o sub.txt 保存子域名
批量收集 subfinder -dL domains.txt 多目标收集
只输出域名 subfinder -d example.com -silent 方便管道处理
查看来源 subfinder -d example.com -v 显示数据来源
使用全部数据源 subfinder -d example.com -all 增加发现数量

httpx

批量对ip进行探活

状态码

常见 HTTP 状态码如下：

状态码 类别 含义 常见场景
100 1xx Continue 请求可以继续
101 1xx Switching Protocols 协议切换，如 WebSocket
200 2xx OK 请求成功
201 2xx Created 成功创建资源
202 2xx Accepted 已接受，异步处理
204 2xx No Content 成功但无响应内容
206 2xx Partial Content 分段下载
301 3xx Moved Permanently 永久重定向
302 3xx Found 临时重定向
303 3xx See Other 重定向到其他资源
304 3xx Not Modified 使用缓存内容
307 3xx Temporary Redirect 临时重定向，保持请求方法
308 3xx Permanent Redirect 永久重定向，保持请求方法
400 4xx Bad Request 请求格式错误
401 4xx Unauthorized 需要身份认证
403 4xx Forbidden 服务器拒绝访问
404 4xx Not Found 资源不存在
405 4xx Method Not Allowed 请求方法不允许
408 4xx Request Timeout 请求超时
409 4xx Conflict 请求产生资源冲突
413 4xx Payload Too Large 请求数据过大
429 4xx Too Many Requests 请求过于频繁，被限流
500 5xx Internal Server Error 服务器内部错误
501 5xx Not Implemented 服务器不支持该功能
502 5xx Bad Gateway 网关收到无效响应
503 5xx Service Unavailable 服务暂时不可用
504 5xx Gateway Timeout 网关等待上游超时

使用 httpx 探测时，重点关注：

  • 200：页面正常可访问
  • 301/302/307/308：存在跳转
  • 401/403：存在资源但需要认证或被限制
  • 404：资源不存在
  • 429：触发限速
  • 500/502/503/504：服务器或上游服务异常
